Launch sequence

No installer.

  1. Download the Windows ZIP from the release channel.
  2. Extract the entire archive. Keep the EXE and PCK in the same folder.
  3. Run TriLink.exe. Windows SmartScreen may ask for confirmation on an unsigned prototype build.
  4. Connect controllers or use the two keyboard layouts, then select Play.
